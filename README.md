## ⚙️ Prérequis
Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine :

- **python** (version 3.10.8)
- **Django** (Django==5.0.6) 
-**VSCODE** (telecharger le vscode pour voir environement de travail)
- Assurer vous que les python et mysql il sont bien dans le path(mettre dans le variable d'environnement )
- creer une base de donner appeler marches_db et importer dans eu le fichier que je vais t'envoyer

### Les commandes a lancer
- **python manage.py makemigrations**
 va te permetre des creer les migrations
-**python manage.py migrate**
 -Appliquer les migrations sur la base  de donner
 **python manage.py runserver**
 Pour Executer le server 
 cliquer http://127.0.0.1:8000/ pour tu acceder a l'application
